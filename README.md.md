# Репозиторий НИР: перевод песен в мюзиклах (дубляж vs субтитры)

**Тема исследования:** сопоставление переводческих стратегий при
дубляже и субтитрировании песен в кино-мюзиклах

**Структура:**
- `00_Inbox` — необработанные идеи и наблюдения
- `01_Literature` — конспекты источников по теории перевода песен и АВП
- `02_Notes` — концептуальные заметки и связи между понятиями
- `03_Projects` — план и этапы исследования
- `04_Drafts` — черновики разделов работы
- `05_Output` — готовые фрагменты для сдачи/публикации
- `_Templates` — шаблоны заметок
- `_Attachments` — таблицы, скриншоты, вспомогательные материалы
