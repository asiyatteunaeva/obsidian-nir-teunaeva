
За единицу анализа берётся строфа. 
Каждая строфа оценивается по пяти критериям [[Принцип пятиборья Лоу]]:
singability, sense, naturalness, rhyme, rhythm. Форматы сопоставляются
по типологии из [[Franzon 2008 - три формата перевода песни]].

 Процедура разметки
1. Для каждой строфы выписываются версия дубляжа и версия субтитров
   (аналитически, без воспроизведения текста целиком).
2. Определяется критерий-приоритет: какому из пяти критериев
   переводчик, судя по результату, отдал предпочтение.
3. Фиксируется переводческая стратегия (замена образа, опущение,
   компенсация, буквальный перевод) и делается краткий комментарий.

Пробная разметка:

| Критерий-приоритет | Комментарий                                      |
| ------------------ | ------------------------------------------------ |
| rhyme + rhythm     | смысловой образ заменён на близкий по звучанию   |
| rhythm             | одна деталь опущена ради числа слогов            |
| sense              | в этой строфе дубляж неожиданно точнее субтитров |
